# GUI 设计说明（工作区）

> 目标：把 CLI 的「扫描 → 排队 → 等待保活 → 提交」变成看得见、可中断、可核对的桌面/移动界面。
> 领域：产品工作区（反复处理对象与状态）。基准视口 1440×900，最小 1024×720；移动端 390×844。

## 1. 对象与任务

层级固定为 **课程 → 单元 → 小节**，一次运行是对「小节队列」的长动作（每节 5–8 分钟）。
所以主结构选 **队列 + 详情**，而不是表格或表单：

- 左：我在哪门课、哪个单元、进度多少
- 中：这一批要处理什么、每节什么状态
- 右：现在跑到哪、还要多久、刚才发生了什么

## 2. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 64  课程名 · 进度            [已登录]      [开始运行]    │
├──────────┬───────────────────────────────┬───────────────────┤
│ 左 264   │ 中 flex                        │ 右 372（可折叠）  │
│ 课程卡   │ 工具栏：筛选 / 跳过口语 / 搜索  │ 当前节卡片        │
│ 单元列表 │ 小节队列（行内状态）           │ 倒计时 · 心跳     │
│          │                               │ 日志流            │
├──────────┴───────────────────────────────┴───────────────────┤
│ 底栏 44  队列进度条   成功 3 · 失败 1 · 跳过 2   剩余 12m     │
└──────────────────────────────────────────────────────────────┘
```

- 顶栏与标题合并，不做双层大标题；课程名本身即上下文。
- 右栏可折叠：窄屏（< 1200）默认收起，日志改为底部抽屉。
- 移动端：单列 —— 课程/单元收进抽屉，主区是队列，运行面板从底部上滑。

## 3. 设计变量

| 角色 | 值 |
| --- | --- |
| 画布 | `#F5F6F8` |
| 内容面 | `#FFFFFF` |
| 分隔线 | `#E6E8EC` |
| 主文字 / 次文字 / 弱文字 | `#1A1D21` / `#5B6470` / `#8A919C` |
| 强调（主按钮、"进行中"） | `#0F766E` |
| 成功 / 警告 / 失败 / 跳过 | `#15803D` / `#B45309` / `#B91C1C` / `#6B7280` |
| 圆角 | 6 控件 · 10 卡片 · 999 胶囊 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 |
| 字体 | 中文 `Microsoft YaHei UI → PingFang SC → Noto Sans SC`；数字等宽 `Consolas → Roboto Mono` |

强调色只出现在两处：主按钮和「进行中」状态。其余状态用中性色 + 图标区分，避免页面变成红绿灯。

## 4. 状态语义

| 状态 | 表现 |
| --- | --- |
| 待处理 | 空心圆点，弱文字 |
| 进行中 | 实心圆点 + 呼吸动效 + 倒计时，整行轻微提亮 |
| 已完成 | 勾，成功色 12% 底 |
| 部分成功 | 半环，警告色 12% 底 |
| 失败 | 感叹号，失败色 12% 底，行尾可展开原因 |
| 跳过 | 斜杠圆点，弱文字，整行降透明 |
| 已中断 | 顿号，中性色 |

颜色不单独承载语义：每种状态都配图标与文字标签。

## 5. 关键交互

- **开始运行**：主按钮变成「暂停」，同时顶栏出现当前节倒计时；暂停 = abort，当前节不提交（与 CLI 语义一致）。
- **行点击**：右栏切到该节的解析结果（题数、题型分布、前几题答案），运行中也可查看，不打断。
- **失败行**：展开显示错误码与原因，附「重试本节」。
- **筛选**：全部 / 待处理 / 失败；切换不重置滚动位置。
- **设置**：等待区间、正确率、跳过口语 —— 底部抽屉，运行中只读。

## 6. 动效（只做三处）

1. 行状态切换：底色与圆点 180ms 过渡。
2. 日志新行：120ms 淡入 + 轻微上移 4px。
3. 倒计时数字：等宽不跳动，不做滚动数字。

## 7. 数据真实性

界面上不出现"示例""示意"字样。未接入的能力（如账号密码登录）在入口处直接置灰并说明原因，不假装可用。
