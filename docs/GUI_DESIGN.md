# GUI 设计说明（工作区）

> 目标：把 CLI 的「扫描 → 排队 → 等待保活 → 提交」变成看得见、可中断、可核对的桌面/移动界面。
> 领域：产品工作区（反复处理对象与状态）。基准视口 1440×900，最小 1024×720；移动端 390×844。

## 1. 对象与任务

层级固定为 **课程 → 单元 → 小节**，一次运行是对「小节队列」的长动作（每节 5–8 分钟）。
所以主结构选 **队列 + 详情**，而不是表格或表单：

- 左：我在哪门课、哪个单元、进度多少
- 中：这一批要处理什么、每节什么状态
- 右：现在跑到哪、还要多久、刚才发生了什么

## 2. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 64  课程名 · 进度         [已登录 ▾] [⚙]   [开始运行]    │
├──────────┬───────────────────────────────┬───────────────────┤
│ 左 264   │ 中 flex                        │ 右 372（可折叠）  │
│ 课程卡   │ 工具栏：筛选 / 跳过口语 / 搜索  │ 当前节卡片        │
│ 单元列表 │ 小节队列（行内状态）           │ 倒计时 · 心跳     │
│          │                               │ 日志流            │
├──────────┴───────────────────────────────┴───────────────────┤
│ 底栏 44  队列进度条   成功 3 · 失败 1 · 跳过 2   剩余 12m     │
└──────────────────────────────────────────────────────────────┘
```

> 上图是早期「顶栏 + 三栏」草稿。当前实现是 **左侧导航 + 单页内容（面板 / 任务 / 设置）**，
> 运行参数在任务页、设置是独立整页，不再有全局顶栏按钮组与右侧常驻面板。
> 下面的对齐规则、§3 设计变量与 §4 状态语义仍适用于当前实现；布局图只作历史背景，不作为验收基线。

- 顶栏与标题合并，不做双层大标题；课程名本身即上下文。
- 右栏可折叠：窄屏（< 1200）默认收起，日志改为底部抽屉。
- 移动端：单列 —— 课程/单元收进抽屉，主区是队列，运行面板从底部上滑。

### 对齐规则（硬约束）

| 规则 | 值 | 原因 |
| --- | --- | --- |
| 平台密度 | `VisualDensity.standard` | 桌面端默认 compact，会把每个按钮压矮 8px（32→24），与固定高度的胶囊/图标按钮对不齐；输入框内文也会偏上。已在 `buildTheme()` 里显式覆盖 |
| 工具栏控件高度 | 32 | 状态胶囊、图标按钮、主按钮三者必须等高；33/34/40 混排会显得参差 |
| 栏内左右边距 | 16 | 标题、卡片、列表、按钮统一 16；出现 12 就会出现"卡片比标题宽一圈" |
| 控件间距 | 8 | 顶栏右侧按钮组固定 8 |
| 同一行的不同字号 | 基线对齐 | 时间/级别/正文、标签/数值按 alphabetic baseline 对齐，而非盒顶对齐 |
| 图标与文字 | 居中 + 固定图标尺寸 | 图标 16 / 胶囊内 13，禁止用字号推图标大小 |
| 小三角等装饰 | CustomPaint 绘制 | 图标字体子集可能漏字形，`Icons.expand_more` 会变成 15px 空白占位，用户看不出可以点 |
| 设置分组卡片 | 内层 `Column` 必须 `crossAxisAlignment.stretch` | Column 默认居中，会让分隔线短一截、按钮组整块居中；分组标题 `left: 16` 与卡片内文对齐 |
| 设置行右侧控件 | 统一放进 32 高槽位，且 `Align.topRight` | 按钮 / 文字 / 开关默认高度不同，混排会把整行拉得参差；顶部对齐让「桌面端可用」这类纯文字与标题同一行，而不是掉到说明行上 |
| 面板卡片网格 | 上下两行共用同一条 2:1 分栏 | 上行运行卡 / 单元卡、下行最近完成 / 日志必须共用同一个右栏宽度，否则两条竖向接缝错开，整页看起来没对齐 |
| 扫描中布局 | 取消 `fill` 拉伸 | 扫描横幅会占掉一行高度，继续拉满会把运行卡固定内容压到溢出；扫描期间改为自然高度滚动 |
| 指标卡 | `minHeight: 86` | hint 有无会让四张卡底边不齐；不要用 `Row` 的 `stretch`，面板在滚动视图里拿到的是无限高度约束 |
| 任务单元组头 | 手机高度与勾选点击区都用 44 | 组头若还是 36 / 34，会与下面 44 点击区的行错开 5px，两个勾选框的竖列对不齐 |
| 运行卡「接下来」 | `fill` 时按剩余高度只显示完整行（行高约 22） | 长标题或 800 高窗口下，固定 4 行会被卡片底边裁掉；半截文字比少显示一行更难读 |
| 任务页主操作按钮 | 44 高 + 纵向内边距 10 | 全局 `FilledButton` 纵向内边距 14，14 + 18 图标 + 14 会超过 44，150% 缩放下文字容易被压扁 |
| 账号卡说明行 | 与按钮行留 6px，距卡片底 10 + 4 | 说明文字紧贴按钮行会显得偏上，和卡片底边也没有呼吸感 |

账号入口收进「已登录」胶囊的下拉菜单：切换课程、重新扫描、退出登录。退出登录需二次确认，因为本机保存的 Cookie 会被一并清除。

## 3. 设计变量

| 角色 | 值 |
| --- | --- |
| 画布 | `#F5F6F8` |
| 内容面 | `#FFFFFF` |
| 分隔线 | `#E6E8EC` |
| 主文字 / 次文字 / 弱文字 | `#1A1D21` / `#5B6470` / `#8A919C` |
| 强调（主按钮、"进行中"） | `#0F766E` |
| 成功 / 警告 / 失败 / 跳过 | `#15803D` / `#B45309` / `#B91C1C` / `#6B7280` |
| 圆角 | 6 控件 · 10 卡片 · 999 胶囊 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 |
| 字体 | 中文 `Microsoft YaHei UI → PingFang SC → Noto Sans SC`；数字等宽 `Consolas → Roboto Mono` |

强调色只出现在两处：主按钮和「进行中」状态。其余状态用中性色 + 图标区分，避免页面变成红绿灯。

## 4. 状态语义

| 状态 | 表现 |
| --- | --- |
| 待处理 | 空心圆点，弱文字 |
| 进行中 | 实心圆点 + 呼吸动效 + 倒计时，整行轻微提亮 |
| 已完成 | 勾，成功色 12% 底 |
| 部分成功 | 半环，警告色 12% 底 |
| 失败 | 感叹号，失败色 12% 底，行尾可展开原因 |
| 跳过 | 斜杠圆点，弱文字，整行降透明 |
| 已中断 | 顿号，中性色 |
| 扫描中 | `accentSoft` 横幅 + 转圈 + 阶段文字（180ms 切换）+ 实时「已用时」+ 不确定进度条，所有扫描按钮禁用并显示「扫描中…」 |

颜色不单独承载语义：每种状态都配图标与文字标签。

扫描是一次要逐单元请求平台的长动作，不能只靠按钮变灰：面板标题下、任务列表区、设置课程卡下都要能看到进度；`AppState.loadCourse` 里还有一层 `scanning` 防重复兜底。

## 5. 关键交互

- **开始运行**：主按钮变成「暂停」，同时顶栏出现当前节倒计时；暂停 = abort，当前节不提交（与 CLI 语义一致）。
- **行点击**：右栏切到该节的解析结果（题数、题型分布、前几题答案），运行中也可查看，不打断。
- **失败行**：展开显示错误码与原因，附「重试本节」。
- **筛选**：全部 / 待处理 / 失败；切换不重置滚动位置。
- **设置**：等待区间、正确率、跳过口语 —— 底部抽屉，运行中只读。

## 6. 动效（只做四处）

1. 行状态切换：底色与圆点 180ms 过渡。
2. 日志新行：120ms 淡入 + 轻微上移 4px。
3. 倒计时数字：等宽不跳动，不做滚动数字。
4. 扫描中：转圈 + 不确定进度条，选中框 180ms 过渡；不做数字滚动，也不做加载遮罩。

## 7. 数据真实性

界面上不出现"示例""示意"字样。未接入的能力（如账号密码登录）在入口处直接置灰并说明原因，不假装可用。
